This page lists all of the items in Fire Emblem Fates.

Item Icon Uses Purchase price Sell price Effects and notes

Strength Tonic 1 150 50 +2 strength for the duration of one mission when used.
Magic Tonic 1 150 50 +2 magic for the duration of one mission when used.

Luck Tonic 1 150 50 +2 luck for the duration of one mission when used.
Defense Tonic 1 150 50 +2 defense for the duration of one mission when used.
Resistance Tonic 1 150 50 +2 resistance for the duration of one mission when used.
Azura's Salve 1 0 0 Recovers 10 HP to all adjacent allies.
Gunter's Potion 1 0 0 Restores 25 HP to its user.
Asugi's Confect 1 0 0 Restores 10 HP to the user, and also grants +2 strength, +2 skill, and +2 speed for the duration of the mission.
Rainbow Tonic 1 0 0 +2 strength, +2 magic, +2 skill, +2 speed, +4 luck, +2 defense, +2 resistance for the duration of one mission when used.
Seed of Trust 1 0 0 Can only be used when paired up and both units of the pair are capable of supporting.
Slightly boosts support between the user and their partner.
Allegro Harp 1 0 0 Trigger Rally Speed for all allies within a two-square radius of the user by 4 each for the rest of the turn.
Shell Horn 1 0 0 Trigger Rally Defense skill for all allies within a two-square radius of the user by 4 each for the rest of the turn.
Door Key 1 0 0 Used to open a single door.
Vanishes after the end of the map if unused.
Chest Key 1 0 0 Used to open a single chest.
Vanishes after the end of the map if unused.
Master Key 1 0 0 Opens any door or treasure chest.
Seraph Robe 1 10,000 1,000 Permanently increases maximum HP by 5 points when used.
Energy Drop 1 10,000 1,000 Permanently increases strength by 2 points when used.
Spirit Dust 1 10,000 1,000 Permanently increases magic by 2 points when used.
Secret Book 1 10,000 1,000 Permanently increases skill by 2 points when used.
Speedwing 1 10,000 1,000 Permanently increases speed by 2 points when used.
Goddess Icon 1 10,000 1,000 Permanently increases luck by 4 points when used.
Dracoshield 1 10,000 1,000 Permanently increases defense by 2 points when used.
Talisman 1 10,000 1,000 Permanently increases resistance by 2 points when used.
Dragon Herbs 1 0 1,000 Permanently increases all stats by 1 point each when used.
Boots 1 0 1,000 Permanently increases movement by 1 point when used.
Cannot be used on the same character more than twice.
Arms Scroll 1 5,000 1,000 Raises the user's weapon levels in all weapon types available to their current class by one tier each.
First Blood 1 0 0 Permanently enables the user to activate Dragon Veins.
Cannot be used by bonus units.
Master Seal 1 2,000 500 Initiates class change for every base class when at Level 10 or higher.
Heart Seal 1 2,000 500 Initiates reclassing for the unit using it.
Partner Seal 1 2,000 500 Allows the unit to reclass into a class tree based on their spouse's base class tree.
Friendship Seal 1 2,000 500 Allows the unit to reclass into a class tree based on their buddy's base class tree.
Offspring Seal 1 0 0 Reclasses the unit into a advanced class and adjust its stats to match.
Usable only by children characters.
Eternal Seal 1 12,000 1,000 When used at an advanced class unit's maximum level, increases the user's maximum level by 5.
Dread Scroll 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Dread Fighter.
Ebon Wing 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Dark Falcon.
Sighting Lens 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Ballistician. Male units only.
Witch's Mark 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Witch. Female units only.
Hero's Brand 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Lodestar. Male units only.
Exalt's Brand 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Great Lord. Female units only.
Fell Brand 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Grandmaster. Male units only.
Vanguard Brand 1 0 0 Initiates reclass for the user (if level 10 base or in an advanced class), promoting them to Vanguard. Male units only.
Paragon 1 -- -- Teaches the skill Paragon to a single unit.
Armor Shield 1 -- -- Unused. Teaches the skill Armor Shield to a single unit.
Beast Shield 1 -- -- Unused. Teaches the skill Beast Shield to a single unit.
Winged Shield 1 -- -- Unused. Teaches the skill Winged Shield to a single unit.
Point Blank 1 -- -- Teaches the skill Point Blank to a single unit.
Bold Stance 1 -- -- Unused. Teaches the skill Bold Stance to a single unit.
Strengthtaker 1 -- -- Teaches the skill Strengthtaker to a single unit.
Magictaker 1 -- -- Teaches the skill Magictaker to a single unit.
Skilltaker 1 -- -- Teaches the skill Skilltaker to a single unit.
Speedtaker 1 -- -- Teaches the skill Speedtaker to a single unit.
Lucktaker 1 -- -- Teaches the skill Lucktaker to a single unit.
Defensetaker 1 -- -- Teaches the skill Defensetaker to a single unit.
Resistancetaker 1 -- -- Teaches the skill Resistancetaker to a single unit.
Heavy Blade 1 -- -- Teaches the skill Heavy Blade to a single unit.
Veteran Intuition 1 -- -- Teaches the skill Veteran Intuition to a single unit.
If used by a base or special class, character must be level 10 minimum.
Advanced classes may use at any level.
Aether 1 -- -- Teaches the skill Aether to a single unit.
Cannot be used by base classes.
If used by a special class, character must be level 25 minimum; if used by an advanced class, character must be level 5 minimum.
Warp 1 -- -- Teaches the skill Warp to a single unit.
Cannot be used by base classes.
If used by a special class, character must be level 35 minimum; if used by an advanced class, character must be level 15 minimum.
Gold Bar -- 0 300 Can be spent to trigger the Spendthrift skill.
Battle Seal -- 0 10,000 +2 strength, magic, skill, and speed when in inventory.
Visitation Seal -- 0 10,000 +2 luck, defense, and resistance when in inventory.
Master Emblem -- 0 10,000 +1 strength, magic, skill, speed, luck, defense and resistance when in inventory.
Obstacle -- 0 0 Allows the user to position the obstacle onto an adjacent tile.
Once placed, the space the "Obstacle" is set onto can no longer be traversed.
They may be picked back up by player units after being placed.
Vanishes after chapter's end if unused.
